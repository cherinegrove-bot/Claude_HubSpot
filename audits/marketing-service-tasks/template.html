M1

Check which delay the {{N.sup}} suppressed companies are actually waiting on

Medium
Intent
The current members were added late (23 Nov) and should wait 25 days. Everyone enrolled from the December run onward waits 45 days. The 25-day path is removed after the next run.
What
The suppression workflow picks the delay with one check: "Is the company in list 5466?" Yes → 45 days. No → 25 days. A company enrolled because it joined 5466 is still in 5466 at that check, so it takes the 45-day path. As built, the 25-day path only runs for a company that has already left the list.
Either way
  • 25 days from 23 Nov: released 18 Dec. 45 days: released 7 Jan.
  • Both are after the December run and before the 5 Feb run. The timing works out whichever path they took.
Check
In the suppression workflow's enrollment history, confirm all {{N.sup}} are enrolled and see which delay they are on. If none are enrolled, they stay suppressed until someone removes them. When the 25-day path is removed after the run, make sure every path still ends with "remove from list 5466".
